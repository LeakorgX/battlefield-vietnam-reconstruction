## file
Move action that follows a path found by the path finder. Goal at this+0x68, current waypoint at this+0x70, path cell data at this+0x78..+0x84.

## 009f1760
Base execute: does nothing, sets flag = 0 and done = 1 and returns 0.

## 009f17a0
vf6: returns the address of the goal point at this+0x68.

## 009f17d0
vf7: copies the two 2-float values at this+0x80 and this+0x78 to the outputs and returns the address of the goal point at this+0x68.

## 009f1830
vf8: writes the byte at this+0x54 to the output and returns the address of the current waypoint at this+0x70.

## 009f1870
vf9: tail call to slot 0xf4 (vf61) of the object at this+0xa0.

## 009f1880
vf12: advances along the path. The bot must be a BotMain (dynamic cast); otherwise returns false. Takes the bot's own position in x/z, asks the bot (slot 0xf0, with this+0x99) for the next waypoint and stores the reached flag at this+0x54, and converts positions with ai_0097f0d0 and helper 00971ab0. When the bot reports a path end (slot 0x114) and the waypoint is further than this+0xa4 (compared squared) it checks whether the waypoint cell changed. The chosen waypoint is stored at this+0x70..+0x74.
